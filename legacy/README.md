# Legacy archive

This folder holds the **original HTML website** and source media before the Next.js rebuild.

It is **not** used by the live app. The production site serves assets from:

`dpm-next/public/images/`

## Contents

- `html/` — original `index.html`
- `images/` — loose root images, sorted by type
- `videos/` — original video files (**local only**, not tracked in Git due to size)
- `source/` — original uploads (`Other Images`, `Services_Image`)
